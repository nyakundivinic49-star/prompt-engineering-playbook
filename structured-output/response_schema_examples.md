# Structured Response Templates

## Example 1: Critical Care Evaluation

### Prompt

Generate the output in JSON format.

### Sample Response

```json
{
  "diagnosis": "Septic Shock",
  "risk_level": "Critical",
  "priority_interventions": [
    "Initiate intravenous fluid therapy",
    "Collect blood cultures",
    "Administer broad-spectrum antibiotics"
  ],
  "monitoring_requirements": [
    "Track blood pressure trends",
    "Assess urine output regularly"
  ]
}
```
