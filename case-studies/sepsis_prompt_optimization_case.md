# Prompt Optimization Case Analysis: Teaching Sepsis Effectively

## Project Goal

Demonstrate how prompt design improvements can enhance the quality, relevance, and educational value of AI-generated healthcare content.

---

## Initial Prompt

> What is sepsis?

---

## Prompt Assessment

The original prompt lacks sufficient guidance for producing a targeted and reliable response.

### Identified Limitations

* No defined audience
* No indication of expected depth or complexity
* No formatting instructions
* No educational objectives
* No safeguards against overly technical language

As a result, outputs may vary significantly in quality, structure, and usefulness.

---

## Refined Prompt Design

Assume the role of a critical care nursing instructor.

Provide a beginner-friendly explanation of sepsis for a nursing student.

Your response should address:

### Required Topics

* What sepsis is
* Common causes and sources of infection
* Early warning signs and symptoms
* Potential complications if untreated
* The importance of rapid recognition and treatment

### Additional Requirements

* Use simple and accessible language
* Organize the response using clear section headings
* Focus on educational value
* Avoid unnecessary medical terminology

---

## Anticipated Outcomes

The revised prompt is expected to generate responses that are:

* Better organized
* More consistent across models
* Easier for learners to understand
* More clinically relevant
* Better aligned with educational goals

---

## Prompt Engineering Insights

This example demonstrates how adding context, audience targeting, and output requirements can significantly improve response quality.

### Key Enhancements Applied

| Improvement Area        | Benefit                                 |
| ----------------------- | --------------------------------------- |
| Audience Specification  | Tailors complexity and tone             |
| Role Assignment         | Encourages domain-specific explanations |
| Structured Instructions | Improves organization                   |
| Content Requirements    | Ensures important topics are covered    |
| Simplicity Constraints  | Enhances readability                    |
